# LSDOT - Servicio de Grúa

Recurso exclusivo de LSDOT. Reutiliza ERS para F11, turno y avisos de grua, y `smvlpd-ranks` para rango y puntos por servicio `tow`.

Antes de activarlo operativamente, configura en `config.lua` una sede LSDOT verificada, el garaje y los modelos autorizados. Añade en `uniforms.lua` solo indices de ropa comprobados en juego.
